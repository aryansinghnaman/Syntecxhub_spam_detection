# 🛡️ SmartShield AI

## Real-Time Email, SMS & Scam Detection Platform

SmartShield AI is an NLP-powered spam and scam detection system built using Machine Learning and Streamlit. The application analyzes emails, SMS messages, and promotional content to identify potentially harmful or fraudulent messages.

## Features

* Spam Detection
* Scam Detection
* Risk Analysis
* Confidence Scoring
* Threat Analysis Dashboard
* Keyword-Based Risk Indicators
* Interactive Streamlit Interface

## Tech Stack

* Python
* Streamlit
* Scikit-Learn
* TF-IDF Vectorization
* Logistic Regression
* Pandas

## Model Performance

* Accuracy: 97.04%
* Dataset: SMS Spam Collection Dataset
